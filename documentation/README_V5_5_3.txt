SAF Link Planner V5.5.4

Esta versión conserva las funciones de V5.5.1/V5.5.2 para:
- Abrir proyectos guardados desde la carpeta configurada.
- Abrir un proyecto desde archivo.
- Cambiar la carpeta de proyectos.
- Volver a la carpeta predeterminada.
- Guardar, crear y borrar proyectos.

Cambios KMZ:
- Terreno con altitud absoluta real del perfil.
- LOS con cotas reales de las antenas A y B.
- Líneas verticales en A y B para mostrar altura de antena.
- Fresnel 60% con cuatro bordes 3D visibles, eje, secciones y corredor 3D transparente.
- Solo advertencias de obstáculos relevantes; no se exporta un pin por cada árbol.
- Obstáculos manuales como geometría 3D.

SAF Link Planner V5

Esta version incorpora:
- Biblioteca de radios y antenas.
- Importacion de datasheets PDF.
- Extraccion automatica de especificaciones.
- Radios Mimosa C6x, C6x-LE y B6x precargados.
- Antenas Mimosa N5-X precargadas.
- Base local data/radios.json y data/antennas.json.
- Perfil con arborizacion y obstaculos.

IMPORTANTE:
El lector de PDF usa pypdf. El lanzador comprueba automaticamente que pypdf este instalado y lo instala si hace falta.

Para iniciar:
1. Ejecute INICIAR_SAF_LINK_PLANNER.bat
2. Espere a que abra el navegador en http://127.0.0.1:8501
3. En Biblioteca RF cargue un datasheet PDF y pulse Analizar.

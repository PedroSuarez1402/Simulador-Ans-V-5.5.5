SAF Link Planner V5.2
=====================

Novedades de esta versión:

1) Radios editables manualmente
- Biblioteca RF > Agregar / editar radio manualmente.
- Todos los campos estándar del catálogo pueden modificarse:
  fabricante, modelo, fuente, frecuencia mínima/máxima, potencia TX,
  ganancia integrada, throughput, anchos de canal, MIMO, modulación,
  sensibilidad RX por canal y notas.
- Parámetros específicos de fabricante pueden guardarse en "Parámetros adicionales (JSON)".
- Se puede editar o eliminar cualquier radio existente.

2) Antenas editables manualmente
- Se mantienen las funciones de V5.1 para crear, editar y eliminar antenas.
- Incluye dimensiones, peso, ganancia, beamwidth, blindaje, polarización,
  conectores, montaje, viento, F/B, XPD, VSWR y demás campos disponibles.

3) Alturas de vegetación automáticas modificables
- Arborización/edición > Modificar manualmente la altura de la vegetación automática.
- Se pueden definir tramos por distancia A-B y asignar una altura manual sobre terreno.
- Altura 0 m permite quitar la vegetación automática de ese tramo.

4) Obstáculos manuales
- Árbol, vegetación, edificio, casa, torre, poste, muro, bodega, estructura u otro.
- Distancia, altura sobre terreno, ancho y estado activo son editables.

La versión anterior V5.1 no se modifica; esta carpeta es una nueva versión de trabajo.
